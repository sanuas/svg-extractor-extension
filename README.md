# SVG Extractor Extension

A simple and efficient Google Chrome extension to list and download all SVG's from the current web page.

---

## 🌐 Overview

**SVG Extractor** is designed to help users effortlessly collect SVG's from any webpage. With just a click, you can view and download SVG's for content creators, researchers, or anyone needing bulk media retrieval.

Developed by **ITS - Info Twist Solutions**  
🔗 [its.net.in](https://its.net.in)

---

## 🚀 Features

- 🔍 Extracts all visible SVG's from the current tab
- 📥 One-click to download option
- 🖼 Preview media before saving
- ⚡ Fast, lightweight, and privacy-friendly

## 🧷 How to Pack It:

1. Place all files in one folder.
2. Right-click → "Compress"/"Send to ZIP" → Name it `svg_extractor.zip`.
3. Go to `chrome://extensions/` → Enable **Developer mode** → Click **Load unpacked** → Select the folder.
